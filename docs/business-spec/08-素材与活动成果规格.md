## 2. 素材审核体系（已冻结）

### 2.1 校内素材流程

```
老师或校管上传 → 提交校内审核 → 校管审核 → 校内可用
```

### 2.2 平台公开素材流程

```
校内审核通过 → 学校管理员提交平台公开审核 → 超级管理员审核 → 平台公开审核通过 → 学校管理员正式发布 → 已公开
```

## 5. 素材状态（已冻结）

> 素材使用两个独立状态字段：`internal_status`（校内使用状态）和 `public_status`（平台公开状态）。

### 5.1 校内使用状态（internal_status）

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 草稿 | 素材正在编辑 | 新建、校内审核驳回 | 待校内审核 | 上传者 | 否 |
| 待校内审核 | 等待学校管理员审核 | 草稿 | 校内审核通过、校内审核驳回 | 学校管理员 | 否 |
| 校内审核通过 | 素材可以被校内业务引用 | 待校内审核、校内已停用 | 校内已停用 | 学校管理员 | 否 |
| 校内审核驳回 | 素材未通过校内审核 | 待校内审核 | 草稿 | 学校管理员 | 否 |
| 校内已停用 | 素材不得被新的校内业务引用 | 校内审核通过 | 校内审核通过 | 学校管理员 | 否 |

### 5.2 平台公开状态（public_status）

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 未提交 | 尚未申请平台公开 | 新建、平台已下架 | 待平台公开审核 | 学校管理员 | 否 |
| 待平台公开审核 | 等待超级管理员审核 | 未提交、平台公开审核驳回 | 平台公开审核通过、平台公开审核驳回 | 超级管理员 | 否 |
| 平台公开审核通过 | 已允许公开但尚未发布 | 待平台公开审核 | 已公开 | 学校管理员 | 否 |
| 平台公开审核驳回 | 平台审核不通过 | 待平台公开审核 | 待平台公开审核、未提交 | 超级管理员 | 否 |
| 已公开 | 素材已进入平台公共区域 | 平台公开审核通过 | 平台已下架 | 学校管理员/超级管理员 | 否 |
| 平台已下架 | 素材已从平台公共区域撤回 | 已公开 | 未提交 | 学校管理员/超级管理员 | 否 |

### 5.3 两个状态的联动约束

- 【AI-DECIDED】 只有 `internal_status = 校内审核通过` 时，才允许提交平台公开审核。
- 【AI-DECIDED】 素材已经公开后，校内状态变为"校内已停用"时，平台公开状态自动转为"平台已下架"。
- 【AI-DECIDED】 平台已下架不改变校内使用状态。
- 【AI-DECIDED】 校内恢复为"校内审核通过"不自动恢复平台公开。
- 【AI-DECIDED】 平台重新公开必须重新提交审核。
- 【AI-DECIDED】 校内审核驳回时，平台公开状态必须为"未提交"。
- 【AI-DECIDED】 两个状态字段必须分别保存状态变更记录。

## 6. 活动成果（已冻结）

### 6.1 成果编辑

- 【SOURCE-CONFIRMED】 校管编辑活动成果（PDF 5.16）
- 【AI-DECIDED】 成果必须关联活动
- 【AI-DECIDED】 可引用校内审核通过的素材
- 【AI-DECIDED】 成果内容：文字总结 + 图片/视频 + 成绩亮点

### 6.2 成果发布

- 【SOURCE-CONFIRMED】 校内成果由校管发布（PDF 1.2, 5.16）
- 【AI-DECIDED】 拟进入平台公共展示时需超管公开审核
- 【AI-DECIDED】 可更新，更新记录更新时间
- 【AI-DECIDED】 已公开成果可下架，下架不删除历史内容

### 6.3 成果更新规则

- 【AI-DECIDED】 平台公开成果修改标题、文字内容、成绩亮点、引用素材等核心内容后，必须重新进行平台公开审核。
- 【AI-DECIDED】 仅修改错别字、排版或不改变原意的信息时，可以保留公开状态，但必须记录修改日志。
- 【AI-DECIDED】 被引用素材下架、授权失效或内容异常时，成果必须进入"公开异常待处理"状态。
- 【AI-DECIDED】 成果处于"公开异常待处理"期间，系统临时隐藏异常素材，作为展示保护措施。
- 【AI-DECIDED】 临时隐藏素材不替代状态流转。
- 【AI-DECIDED】 学校管理员必须处理异常并提交修正。
- 【AI-DECIDED】 核心内容变化后需重新进行平台公开审核。
- 【AI-DECIDED】 无法修复时，成果进入"平台已下架"。
- 【AI-DECIDED】 成果公开审核通过不等于自动发布；学校管理员执行公开发布。
- 【AI-DECIDED】 超级管理员只能将成果审核为"平台公开审核通过"或"平台公开审核驳回"，不得代替学校管理员执行正常公开发布。
- 【AI-DECIDED】 学校管理员在审核通过后执行正式发布，状态由"平台公开审核通过"变为"平台公开"。
- 【AI-DECIDED】 超级管理员可以因违规、安全或授权问题强制下架；下架必须填写原因。
- 【AI-DECIDED】 超级管理员因违规、安全、授权失效等原因可以强制将平台公开成果下架。
- 【AI-DECIDED】 强制下架必须填写原因并通知学校管理员。

### 公开异常状态触发条件

以下情况成果进入"公开异常待处理"：

- 被引用素材被平台下架；
- 被引用素材的公开授权被撤回；
- 展示的学生身份授权失效；
- 成绩或排行榜更正导致成果中的成绩亮点失效；
- 学校暂停或停用；
- 平台发现内容安全风险。

处理方式：

- 可移除异常素材或修改内容后恢复公开（→平台公开）；
- 核心内容发生变化时必须重新提交平台审核；
- 无法修复时转为平台已下架；
- 所有处理过程必须保存记录。

### 6.4 活动基本信息、成果和素材的公开独立性

- 【AI-DECIDED】 活动基本信息公开、活动成果公开和素材公开是三个独立对象。
- 【AI-DECIDED】 活动基本信息审核通过，不代表其素材或成果自动公开。
- 【AI-DECIDED】 活动成果拟进入平台公共展示时，成果本身及被引用素材均须满足相应公开审核条件。

### 6.5 活动成果状态（独立于活动执行状态）

> 成果使用两个独立状态字段：`result_internal_status`（校内发布状态）和 `result_public_status`（平台公开状态）。

#### 校内成果状态（result_internal_status）

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 草稿 | 成果正在编辑 | —、校内已撤回 | 校内已发布 | 学校管理员 | 否 |
| 校内已发布 | 本校可见 | 草稿 | 校内已撤回 | 学校管理员 | 否 |
| 校内已撤回 | 停止校内展示 | 校内已发布 | 草稿 | 学校管理员 | 否 |

流转：`草稿 → 校内已发布 → 校内已撤回 → 草稿`

#### 平台公开状态（result_public_status）

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 未提交 | 尚未申请平台公开 | —、平台公开审核驳回、平台已下架 | 待平台公开审核 | 学校管理员 | 否 |
| 待平台公开审核 | 等待超级管理员审核 | 未提交 | 平台公开审核通过、平台公开审核驳回 | 超级管理员 | 否 |
| 平台公开审核通过 | 已允许公开但尚未正式发布 | 待平台公开审核 | 已公开 | 学校管理员 | 否 |
| 平台公开审核驳回 | 平台审核未通过 | 待平台公开审核 | 未提交 | 超级管理员 | 否 |
| 已公开 | 已向所有人公开 | 平台公开审核通过 | 公开异常待处理、平台已下架 | 学校管理员或超级管理员 | 否 |
| 公开异常待处理 | 引用素材、授权或内容发生异常 | 已公开 | 已公开、未提交、平台已下架 | 学校管理员或超级管理员 | 否 |
| 平台已下架 | 从平台公开区域撤回 | 已公开、公开异常待处理 | 未提交 | 学校管理员或超级管理员 | 否 |

流转：
```
未提交 → 待平台公开审核 → 平台公开审核通过 → 已公开
待平台公开审核 → 平台公开审核驳回 → 未提交
已公开 → 公开异常待处理 → 已公开 / 未提交 / 平台已下架
已公开 → 平台已下架 → 未提交
```

### 联动规则

- 【AI-DECIDED】 只有校内状态为"校内已发布"时才能提交平台审核。
- 【AI-DECIDED】 校内撤回时，若成果已平台公开，则平台状态自动转为平台已下架。
- 【AI-DECIDED】 平台已下架不自动改变校内状态。
- 【AI-DECIDED】 校内恢复发布不自动恢复平台公开。
- 【AI-DECIDED】 核心内容修改后，公开状态回到未提交并生成新审核版本。
- 【AI-DECIDED】 "公开异常待处理→已公开"仅限未修改核心内容且异常因素已恢复。
- 【AI-DECIDED】 修改核心内容时必须进入未提交，不得直接恢复已公开。

### 成果审核记录

- 【AI-DECIDED】 不得只使用一个状态字段代替审核历史，必须保留独立审核记录和版本。
