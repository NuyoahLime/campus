## 2. 活动申请流程（已冻结）

```
普通老师 → 提交活动申请 → 学校管理员审批 → 通过 → 形成活动草稿
                                          → 驳回 → 通知老师（可修改重提）
```

| 规则 | 标签 |
|------|------|
| 普通老师可以提交活动申请 | SOURCE-CONFIRMED |
| 活动申请由学校管理员审批 | AI-DECIDED |
| 申请通过后形成活动草稿 | AI-DECIDED |
| 学校管理员可以不经过申请直接创建本校活动 | AI-DECIDED |
| 超级管理员不审核普通校内活动的创建 | AI-DECIDED |
| 原需求"超管活动审核"解释为审核拟进入平台公共展示的活动/成果 | AI-DECIDED |
| 活动申请与正式活动是两个业务对象 | AI-DECIDED |
| 驳回后允许修改重新提交 | AI-DECIDED |
| 老师可在校管审批前撤回申请 | AI-DECIDED |

### 活动申请状态

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 草稿 | 老师正在编辑 | —、已驳回 | 已提交 | 普通老师 | 否 |
| 已提交 | 等待校管审批 | 草稿 | 已通过、已驳回、已撤回 | 学校管理员 | 否 |
| 已通过 | 已创建活动 | 已提交 | — | — | 是 |
| 已驳回 | 需修改重提 | 已提交 | 草稿（修改后重提） | 学校管理员 | 否 |
| 已撤回 | 老师主动撤回 | 已提交 | — | 普通老师 | 是 |

## 3. 活动执行状态（已冻结）

```
草稿 → 已发布 → 进行中 → 已结束
  ↓        ↓
已取消 ←───
```

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 草稿 | 正式活动已创建但尚未发布 | 活动申请已通过后创建；或学校管理员直接创建 | 已发布、已取消 | 学校管理员 | 否 |
| 已发布 | 已发布，即将开始 | 草稿 | 进行中、已取消 | 学校管理员 | 否 |
| 进行中 | 活动正在进行 | 已发布 | 已结束 | 系统/学校管理员 | 否 |
| 已结束 | 活动正常完成 | 进行中 | — | 学校管理员 | 是 |
| 已取消 | 活动未按计划完成或被提前终止 | 草稿、已发布 | — | 学校管理员 | 是 |

> ⚠️ **重要**: "成果已发布"不是活动执行状态。活动成果拥有独立状态体系。参见 DEC-RESULT-001。

### 状态流转规则

- 【AI-DECIDED】 活动有开始时间和结束时间
- 【AI-DECIDED】 活动结束可手动确认，也可根据结束时间提示管理员确认（V1不自动强制结束）
- 【AI-DECIDED】 草稿可完整编辑
- 【AI-DECIDED】 已发布后名称/时间/项目等关键配置修改需谨慎控制
- 【AI-DECIDED】 草稿和已发布(未开始)可取消
- 【AI-DECIDED】 已有成绩的活动不得物理删除
- 【AI-DECIDED】 已结束活动不得新增普通成绩。
- 【AI-DECIDED】 确需补录时，必须按成绩管理规格中的异常补录流程执行。
- 【AI-DECIDED】 活动申请"已通过"后，系统创建一个新的正式活动对象，正式活动初始状态为"草稿"。
- 【AI-DECIDED】 活动申请对象与正式活动对象使用不同的状态字段。
- 【AI-DECIDED】 活动申请被驳回后，仅活动申请回到可修改状态，不会创建正式活动。
- 【AI-DECIDED】 V1不支持将已结束活动重新恢复为进行中。
- 【AI-DECIDED】 已结束活动仍可进行成果编辑、排行榜生成、申诉处理和异常补录，但这些操作不改变活动执行状态。
- 【AI-DECIDED】 已结束表示活动已经实际执行完成。
- 【AI-DECIDED】 已取消表示活动未按计划完成或被提前终止。
- 【AI-DECIDED】 已取消活动不得恢复为已发布或进行中。
- 【AI-DECIDED】 已取消活动已存在的成绩、素材、成果和审核记录继续保留。

## 4. 活动公开属性（已冻结）

> 活动公开属性独立于活动执行状态，不得将公开审核状态作为活动执行状态。

### 公开范围

| 公开范围 | 含义 |
|---------|------|
| 校内可见 | 仅本校登录用户可见 |
| 平台公开 | 所有人可见，包括访客 |

### 平台公开审核状态

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 未提交 | 尚未申请平台公开 | 新建、学校已撤回、平台已下架、平台审核驳回 | 待平台审核 | 学校管理员 | 否 |
| 待平台审核 | 已提交超级管理员审核 | 未提交 | 平台审核通过、平台审核驳回 | 超级管理员 | 否 |
| 平台审核通过 | 允许平台公开 | 待平台审核 | 已公开 | 学校管理员 | 否 |
| 平台审核驳回 | 不允许平台公开 | 待平台审核 | 未提交 | 超级管理员 | 否 |
| 已公开 | 已在平台公开展示 | 平台审核通过 | 学校已撤回、平台已下架 | 学校管理员/超级管理员 | 否 |
| 学校已撤回 | 学校主动从平台公开撤回 | 已公开 | 未提交 | 学校管理员 | 否 |
| 平台已下架 | 平台从公开区域强制撤回 | 已公开 | 未提交 | 超级管理员 | 否 |

冻结流转：

```
未提交 → 待平台审核 → 平台审核通过 → 已公开 → 已撤回
待平台审核 → 平台审核驳回 → 修改后重新提交 → 待平台审核
```

### 公开审核规则

- 【AI-DECIDED】 只有活动执行状态为"已发布""进行中"或"已结束"的活动可以提交平台公开审核。
- 【AI-DECIDED】 草稿活动和已取消活动不得提交公开审核。
- 【AI-DECIDED】 活动公开申请由学校管理员提交。
- 【AI-DECIDED】 平台审核由超级管理员执行。
- 【AI-DECIDED】 审核通过后由学校管理员执行正式公开。
- 【AI-DECIDED】 平台审核驳回必须填写理由。
- 【AI-DECIDED】 驳回后修改公开内容可重新提交。
- 【AI-DECIDED】 学校管理员可以主动撤回公开活动。
- 【AI-DECIDED】 超级管理员可以因违规、安全或授权问题强制下架。
- 【AI-DECIDED】 活动被取消时，活动基本信息自动停止公开，但其历史成果是否保留由成果公开规则独立决定。
- 【AI-DECIDED】 活动基本信息公开、活动成果公开和素材公开是三个独立对象，三者不得共用一个审核状态字段。

### 公开审核修改触发

- 【AI-DECIDED】 已公开活动修改名称、时间、项目、活动说明、公开范围等核心字段后，必须重新进入平台审核。
- 【AI-DECIDED】 已公开活动仅修改不影响内容含义的格式信息时，可以不重新审核，但必须记录修改日志。

### 活动公开审核记录字段

| 字段 |
|------|
| 活动ID |
| 公开申请版本 |
| 提交人 |
| 提交时间 |
| 审核人 |
| 审核时间 |
| 审核结果 |
| 审核意见 |
| 驳回原因 |
| 公开人 |
| 公开时间 |
| 撤回或下架原因 |
| 当前公开版本 |

## 5. 活动配置（已冻结）

### 5.1 项目选择

- 【AI-DECIDED】 一个活动可以包含多个挑战项目
- 【AI-DECIDED】 每个活动项目使用引用时的项目规则版本（规则快照）
- 【SOURCE-CONFIRMED】 从平台项目资源库引用

### 5.2 负责老师

- 【AI-DECIDED】 每个活动项目至少指定一名主要负责老师，可多名
- 【AI-DECIDED】 普通老师只能操作本人被分配的活动项目
- 【AI-DECIDED】 负责老师职责：录入成绩 + 查看负责项目数据 + 上传素材（不可审核成绩）

### 5.3 参与学生

- 【AI-DECIDED】 活动应明确参与学生范围
- 【AI-DECIDED】 参与学生可按个人/班级/年级配置
- 【AI-DECIDED】 校管负责最终配置参与范围
- 【AI-DECIDED】 负责老师可协助维护参与名单
- 【AI-DECIDED】 V1不支持学生自主报名
- 【AI-DECIDED】 未被纳入参与范围的学生不能产生该活动项目的有效成绩
