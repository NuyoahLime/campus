## 1. 统一基础规则

1. 【AI-DECIDED】 已产生业务关联的数据不得物理删除。
2. 【AI-DECIDED】 审核、审批、申诉、更正、异常补录和审计记录不得修改历史结论。
3. 【AI-DECIDED】 用户停用后，历史活动、成绩、审核记录和申诉继续保留。
4. 【AI-DECIDED】 学校停用后，历史数据保留，账号禁止登录，公开内容按规则下架。
5. 【AI-DECIDED】 项目下架不影响历史活动中的项目快照。
6. 【AI-DECIDED】 活动取消不删除既有成绩、素材、成果和审核记录。
7. 【AI-DECIDED】 成绩更正通过后，原成绩转为失效，不物理删除。
8. 【AI-DECIDED】 排行榜更新生成新版本，不覆盖旧版本。
9. 【AI-DECIDED】 素材和成果下架后保留原始文件、版本和审核记录。
10. 【AI-DECIDED】 数据恢复不得自动恢复原公开状态，公开内容必须重新确认。

## 2. 入驻申请

| 属性 | 规则 |
|------|------|
| 物理删除 | 【AI-DECIDED】 仅从未提交的草稿入驻申请允许物理删除 |
| 已提交后撤回 | 【AI-DECIDED】 不得物理删除；保留撤回人、撤回时间和撤回原因 |
| 需补充/已驳回/已通过 | 【AI-DECIDED】 不得物理删除 |
| 归档 | 【AI-DECIDED】 已驳回和已通过的申请超过保留期后归档 |
| 关联限制 | 已通过的申请关联已创建的学校记录，删除学校前必须先处理关联申请 |

## 5. 挑战项目

| 属性 | 规则 |
|------|------|
| 物理删除 | 【AI-DECIDED】 仅草稿且从未产生业务关联的项目可以物理删除 |
| 已上架项目 | 【AI-DECIDED】 不得物理删除 |
| 已下架项目 | 【AI-DECIDED】 不得物理删除，可以重新上架 |
| 历史规则版本 | 【AI-DECIDED】 永久保留或按长期归档策略保存 |
| 活动快照 | 【AI-DECIDED】 不受项目下架、重新上架和规则更新影响 |
| 状态记录 | 【AI-DECIDED】 上架、下架和重新上架必须保存状态操作记录 |

## 6. 活动申请

| 属性 | 规则 |
|------|------|
| 物理删除 | 【AI-DECIDED】 仅从未提交的草稿可以物理删除 |
| 已提交 | 【AI-DECIDED】 不得物理删除 |
| 已撤回 | 【AI-DECIDED】 已提交后撤回的申请不得物理删除；从未提交的草稿撤销可删除 |
| 已驳回 | 【AI-DECIDED】 不得物理删除，保留驳回理由和审核记录 |
| 已通过 | 【AI-DECIDED】 不得物理删除，必须关联正式活动 |
| 修改与重提 | 【AI-DECIDED】 驳回后修改重提应保留申请版本，不覆盖历史版本 |
| 历史记录 | 【AI-DECIDED】 提交、撤回、驳回、通过和审批记录均应保留 |
| 归档 | 【DEFERRED-P1: P1-DATA-RETENTION-POLICY-001】 具体归档期限由数据保留策略配置 |

- 【AI-DECIDED】 活动申请和正式活动是两个独立生命周期对象。
- 【AI-DECIDED】 活动申请通过后创建正式活动，不得把活动申请状态写入活动执行状态。
- 【AI-DECIDED】 正式活动删除、取消或结束不删除活动申请历史记录。

## 7. 活动

| 属性 | 规则 |
|------|------|
| 物理删除 | 【AI-DECIDED】 仅草稿且无关联数据的活动可物理删除 |
| 终态 | 【AI-DECIDED】 已结束为不可恢复终态；已取消为不可恢复终态 |
| 取消 | 【AI-DECIDED】 取消后不删除既有成绩、素材、成果和审核记录 |
| 对公开内容影响 | 【AI-DECIDED】 取消后活动基本信息自动停止公开，历史成果按独立规则处理 |
| 恢复 | 【AI-DECIDED】 V1不支持将已结束活动恢复为进行中；已取消活动不可恢复 |
| 对象隔离 | 【AI-DECIDED】 活动申请状态不得写入活动执行状态；两者使用不同状态字段 |

## 9. 排行榜相关对象

> 不存在通用"排行榜"生命周期。只保留以下三个独立对象。

### 9.1 排行榜定义

| 属性 | 规则 |
|------|------|
| 版本物理删除 | 【AI-DECIDED】 草稿计算和已生成版本只能作废；已发布、已撤回、已过期、已被替换版本不得物理删除 |
| 撤回 | 【AI-DECIDED】 撤回后保留历史版本 |
| 更新 | 【AI-DECIDED】 更新生成新版本，不覆盖旧版本 |
| 过期 | 【DEFERRED-P2: P2-RANK-DISPLAY-EXPIRY-001】 展示期限规则在详设阶段确定 |

### 排行榜定义

| 属性 | 规则 |
|------|------|
| 物理删除 | 【AI-DECIDED】 已生成任何版本后不得物理删除 |
| 停用 | 【AI-DECIDED】 可以停用；停用后不得生成新版本 |
| 恢复 | 【AI-DECIDED】 重新启用后可以生成新版本；历史版本不受定义停用影响 |

### 排行榜版本

| 属性 | 规则 |
|------|------|
| 物理删除 | 【AI-DECIDED】 草稿计算和已生成版本可作废；已发布版本不得物理删除 |
| 终态 | 【AI-DECIDED】 已撤回、已过期和已被替换为终态；终态版本不得恢复为草稿 |
| 新建 | 【AI-DECIDED】 重新计算必须创建新版本 |

### 平台排行榜数据授权

| 属性 | 规则 |
|------|------|
| 物理删除 | 【AI-DECIDED】 仅草稿可物理删除；待审核及之后不得物理删除 |
| 暂停 | 【AI-DECIDED】 审核通过可暂停；暂停可恢复 |
| 撤回 | 【AI-DECIDED】 已撤回不可恢复；重新授权需新建记录或新版本 |
| 历史保留 | 【AI-DECIDED】 历史授权和审核记录长期保留 |

## 10. 申诉

| 属性 | 规则 |
|------|------|
| 物理删除 | 【AI-DECIDED】 不得物理删除 |
| 撤回 | 【AI-DECIDED】 "已提交"状态可由学生直接撤回；"处理中"和"排行核查中"需当前处理人确认；进入"已接受待更正""成绩更正中""排行修正中""已升级""平台处理中"后不得单方面撤回 |
| 历史保留 | 【AI-DECIDED】 所有申诉记录保留，包括驳回和撤回 |
| 撤回记录 | 【AI-DECIDED】 撤回必须保存撤回申请人、申请时间、当前状态、确认人、确认时间、是否同意、撤回原因 |
| 关联影响 | 申诉相关成绩更正和排行榜版本变更独立记录 |
