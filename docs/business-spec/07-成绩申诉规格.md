## 2. 申诉流程（已冻结）

### 2.1 成绩申诉

学生提交成绩申诉 → 校管处理 →
- 驳回：填写理由并结束；
- 接受：创建成绩更正记录 → 重新审核 → 原成绩失效 → 重算相关排行榜 → 通知学生。

### 2.2 排名申诉

学生提交排名申诉 → 校管判断问题类型 →
- 成绩数据错误：转入成绩更正流程；
- 排行计算错误：修复计算并重新生成排行榜版本；
- 排行配置错误：修改排行榜配置并重新生成排行榜版本；
- 身份或展示信息错误：修正关联或展示信息；
- 申诉不成立：填写理由并驳回。

- 【AI-DECIDED】 排名申诉被接受不必然创建成绩更正记录。
- 【AI-DECIDED】 任何影响已发布排行榜结果的处理均应生成新排行榜版本，不得直接覆盖历史版本。

## 3. 申诉权限（已冻结）

| 规则 | 标签 |
|------|------|
| 学生只能申诉本人的成绩或与本人相关的排名 | AI-DECIDED |
| 学校管理员负责本校申诉处理 | AI-DECIDED |
| 原负责老师可以提供说明，但不负责最终裁决 | AI-DECIDED |
| 超级管理员不直接处理普通校内申诉 | AI-DECIDED |

### 升级机制

以下情形可由校管或学生升级到超级管理员处理：

| 情形 | 标签 |
|------|------|
| 涉及平台规则 | AI-DECIDED |
| 涉及跨校公开排行榜 | AI-DECIDED |
| 投诉对象为学校管理员 | AI-DECIDED |
| 学校无法正常处理 | AI-DECIDED |

## 5. 申诉状态（已冻结）

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 已提交 | 学生已提交，等待处理 | — | 处理中、已撤回 | 学校管理员 | 否 |
| 处理中 | 校管正在处理 | 已提交 | 已驳回、已接受待更正、排行核查中、已升级 | 学校管理员 | 否 |
| 已驳回 | 申诉被驳回（说明理由） | 处理中 | — | 学校管理员 | 是 |
| 已接受待更正 | 申诉被接受，等待进入成绩更正流程 | 处理中 | 成绩更正中 | 学校管理员 | 否 |
| 成绩更正中 | 成绩更正流程进行中（→DEC-SCORE-004） | 已接受待更正 | 已解决 | 学校管理员 | 否 |
| 排行核查中 | 正在核查排行榜计算、配置或展示问题 | 处理中 | 排行修正中、已驳回 | 学校管理员 | 否 |
| 排行修正中 | 正在生成修正后的排行榜版本 | 排行核查中 | 已解决 | 学校管理员 | 否 |
| 已升级 | 已提交超级管理员处理 | 处理中 | 平台处理中、平台退回学校 | 超级管理员 | 否 |
| 平台处理中 | 超级管理员正在处理 | 已升级 | 平台退回学校 / 平台已裁决 | 超级管理员 | 否 |
| 平台退回学校 | 需由学校补充材料或重新处理 | 平台处理中 | 处理中（学校补充后再次升级） | 学校管理员 | 否 |
| 平台已裁决 | 超级管理员已作出处理决定，等待执行或通知完成 | 平台处理中 | 已解决 | 超级管理员 | 否 |
| 已解决 | 成绩更正、异常补录、排行榜修正、展示修正或平台裁决已经执行完成，且结果已通知申诉人 | 成绩更正中、排行修正中、平台已裁决 | — | 学校管理员或超级管理员 | 是 |
| 已撤回 | 学生撤回且处理尚未进入不可逆业务流程 | 已提交、处理中、排行核查中 | — | 学生/当前处理人 | 是 |

> ⚠️ 禁止将"已接受"直接等同于"成绩已修正"。

### 撤回规则（已冻结）

- 【AI-DECIDED】 "已提交"状态的申诉可以由学生直接撤回。
- 【AI-DECIDED】 "处理中"和"排行核查中"状态可以申请撤回，由当前处理人确认。
- 【AI-DECIDED】 已进入"已接受待更正""成绩更正中""排行修正中""已升级""平台处理中"后的申诉不得由学生单方面撤回。
- 【AI-DECIDED】 撤回不删除申诉记录。
- 【AI-DECIDED】 撤回原因和撤回时间必须保存。

## 6. 申诉后闭环（已冻结）

### 6.1 成绩申诉闭环

1. 接受成绩申诉；
2. 创建成绩更正或异常补录申请；
3. 重新审核；
4. 原成绩失效或新增成绩生效；
5. 重算相关排行榜；
6. 生成新排行榜版本；
7. 通知学生；
8. 申诉状态转为已解决。

### 6.2 排名申诉闭环

根据问题类型分别处理：

- 成绩数据错误：转入成绩更正流程；
- 排行算法错误：修复计算逻辑，重新生成排行榜版本；
- 排行配置错误：修改配置，重新生成排行榜版本；
- 身份关联错误：修正学生、班级、年级或学校关联；
- 展示信息错误：修正对外展示快照；
- 公开授权错误：转入L3数据授权处理。

> 【AI-DECIDED】 任何影响已发布排行榜内容的修改必须生成新版本，不得覆盖历史版本。

### 6.3 升级申诉闭环

- 【AI-DECIDED】 超级管理员只处理涉及平台规则、跨校L3、投诉校管或学校无法处理的事项。
- 【AI-DECIDED】 升级不代表超级管理员可以直接修改校内成绩。
- 【AI-DECIDED】 涉及成绩修改时，仍由学校进入成绩更正流程。
- 【AI-DECIDED】 涉及L3排行榜时，由超级管理员生成新的平台排行榜版本。
