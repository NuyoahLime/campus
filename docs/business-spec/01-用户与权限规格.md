## 1. 用户角色定义

### 1.1 访客 (Visitor)

| 属性 | 说明 |
|------|------|
| **角色定位** | 未登录的平台浏览者 |
| **认证要求** | 无需登录 |
| **数据范围** | 仅全平台公开数据 |

#### 可执行操作

- 【SOURCE-CONFIRMED】 浏览首页（PDF 5.1）
- 【SOURCE-CONFIRMED】 浏览项目资源库，按分类、场地、器材和成绩指标类型筛选（PDF 5.2）
- 【SOURCE-CONFIRMED】 查看项目详情（PDF 5.3）
- 【SOURCE-CONFIRMED】 查看活动组织指南（PDF 4.1.1）
- 【SOURCE-CONFIRMED】 查看学校活动展示（PDF 5.4）
- 【SOURCE-CONFIRMED】 查看平台公开排行榜（PDF 4.1.1）
- 【SOURCE-CONFIRMED】 下载公开资料（PDF 4.1.1）
- 【SOURCE-CONFIRMED】 访问学校入驻页面并提交入驻申请（PDF 4.1.1）
- 【SOURCE-CONFIRMED】 访问登录页（PDF 5.5）
- 【AI-DECIDED】 提交平台意见反馈（需填写联系方式和验证码）

#### 禁止操作

- 【SOURCE-CONFIRMED】 不可访问学校内部活动数据
- 【SOURCE-CONFIRMED】 不可查看任何学生成绩
- 【SOURCE-CONFIRMED】 不可查看学校内部排行榜
- 【SOURCE-CONFIRMED】 不可使用管理功能

---

### 1.2 学生 (Student)

| 属性 | 说明 |
|------|------|
| **角色定位** | 绑定到某所学校的已登录用户 |
| **认证要求** | 必须登录 |
| **账号归属** | 绑定一所学校 |
| **数据范围** | 本校公开活动 + 本人成绩 + 本校已发布排行榜 |

#### 可执行操作

- 【SOURCE-CONFIRMED】 查看本校已发布活动（PDF 4.1.2）
- 【SOURCE-CONFIRMED】 查看本人的成绩明细（PDF 4.1.2, 5.7）
- 【SOURCE-CONFIRMED】 查看与本人相关的排名（PDF 5.7）
- 【SOURCE-CONFIRMED】 查看本校已发布排行榜（PDF 4.1.2）
- 【SOURCE-CONFIRMED】 浏览项目公共资源（PDF 5.2/5.3）
- 【AI-DECIDED-FROM-CONFLICT】 下载公开资料（CNF-007已消解：统一为允许）
- 【SOURCE-CONFIRMED】 提交反馈（PDF 4.1.2）
- 【SOURCE-CONFIRMED】 提交本人成绩和排名申诉（PDF 4.1.2, 5.8）

#### 禁止操作

- 【SOURCE-CONFIRMED】 不能修改成绩（PDF 5.7）
- 【AI-DECIDED】 不可查看其他学生个人成绩明细
- 【AI-DECIDED】 不可查看未发布排行榜
- 【AI-DECIDED】 不可管理活动和账号

---

### 1.3 普通老师 (Teacher)

| 属性 | 说明 |
|------|------|
| **角色定位** | 绑定到某所学校的已登录用户，辅助组织活动 |
| **认证要求** | 必须登录 |
| **账号归属** | 绑定一所学校 |
| **数据范围** | 本校活动（负责范围）+ 本人上传的素材 |

#### 可执行操作

- 【SOURCE-CONFIRMED】 浏览项目资源、下载资料、收藏项目（PDF 4.1.3）
- 【SOURCE-CONFIRMED】 提交活动申请（PDF 4.1.3）
- 【SOURCE-CONFIRMED】 查看本校活动（PDF 4.1.3）
- 【SOURCE-CONFIRMED】 录入本人负责活动项目的成绩（PDF 5.10）
- 【AI-DECIDED】 修改本人录入且尚未审核通过的成绩
- 【SOURCE-CONFIRMED】 上传活动素材（PDF 5.11）
- 【SOURCE-CONFIRMED】 提交反馈（PDF 5.11）
- 【AI-DECIDED】 查看本人负责项目的参与学生和成绩明细

#### 禁止操作

- 【SOURCE-CONFIRMED】 不可管理其他学校数据
- 【SOURCE-CONFIRMED】 不可审核成绩（审核由学校管理员执行）
- 【SOURCE-CONFIRMED】 不可创建或编辑用户账号
- 【AI-DECIDED】 不可查看与本人职责无关的学生成绩明细
- 【AI-DECIDED】 不可直接发布平台公开内容

---

### 1.4 学校管理员 (School Admin)

| 属性 | 说明 |
|------|------|
| **角色定位** | 负责某一所学校平台运营的管理者 |
| **认证要求** | 必须登录 |
| **账号归属** | 绑定一所学校 |
| **数据范围** | 仅本校全部数据，严格不可跨校 |

#### 可执行操作

- 【SOURCE-CONFIRMED】 管理本校基础资料（PDF 4.1.4）
- 【SOURCE-CONFIRMED】 创建和管理本校老师、学生账号（PDF 5.13）
- 【AI-DECIDED】 可锁定、解锁、停用和重新启用本校学生及普通老师账号
- 【AI-DECIDED】 不可操作其他学校账号；不可管理学校管理员账号
- 【SOURCE-CONFIRMED】 创建和管理本校活动（PDF 1.2, 5.14）
- 【AI-DECIDED】 审批普通老师的活动申请
- 【SOURCE-CONFIRMED】 配置活动项目、分配负责老师（PDF 1.2, 5.14）
- 【AI-DECIDED】 配置参与学生范围
- 【AI-DECIDED-FROM-CONFLICT】 代录本校成绩（CNF-005已消解：采纳PDF 1.2节）
- 【SOURCE-CONFIRMED】 审核本校成绩（PDF 1.2, 2.1）
- 【AI-DECIDED】 学校管理员不得审核本人录入、本人更正或本人发起异常补录的成绩（职责分离）。
- 【SOURCE-CONFIRMED】 管理本校排行榜（PDF 4.1.4）
- 【SOURCE-CONFIRMED】 审核本校素材（PDF 5.16）
- 【SOURCE-CONFIRMED】 发布本校活动成果（PDF 1.2, 5.16）
- 【SOURCE-CONFIRMED】 处理本校反馈和申诉（PDF 5.16）
- 【AI-DECIDED】 导出本校授权范围内数据（DEFERRED-P2）

#### 禁止操作

- 【SOURCE-CONFIRMED】 不得访问其他学校内部数据（PDF 4.1.4）
- 【SOURCE-CONFIRMED】 不得编辑平台项目资源（PDF 5.3）
- 【SOURCE-CONFIRMED】 不得管理平台公开排行榜
- 【AI-DECIDED】 不得审核本人代录的成绩
- 【AI-DECIDED】 不得物理删除已有历史业务数据的用户、活动或成绩

### 1.5 超级管理员 (Super Admin)

| 属性 | 说明 |
|------|------|
| **角色定位** | 平台运营管理人员，平台治理角色 |
| **认证要求** | 必须登录 |
| **账号归属** | 不归属任何学校（平台级） |
| **数据范围** | 全平台治理数据、平台统计数据和必要审计数据；默认不得查看学生个人成绩明细，不得修改学校内部业务数据 |

#### 可执行操作

- 【SOURCE-CONFIRMED】 审核学校入驻（PDF 4.1.5）
- 【AI-DECIDED】 管理学校基础信息（关键信息修改）
- 【SOURCE-CONFIRMED】 管理学校管理员账号（PDF 5.18）；可锁定、解锁、停用和重新启用学校管理员账号
- 【AI-DECIDED】 重大安全风险下可以紧急锁定或停用师生账号，但不得日常管理其业务资料
- 【SOURCE-CONFIRMED】 管理挑战项目及项目分类（PDF 4.1.5, 5.17）
- 【AI-DECIDED】 审核拟进入平台公共区域的活动基本信息、活动成果、素材和排行榜数据授权（按公开范围分级审核）
- 【SOURCE-CONFIRMED】 管理平台公开排行榜（PDF 4.1.5）
- 【SOURCE-CONFIRMED】 处理平台级反馈和升级事项（PDF 4.1.5）
- 【SOURCE-CONFIRMED】 查看平台运行统计（PDF 5.19）
- 【AI-DECIDED】 查看必要的审计信息和汇总数据
- 【SOURCE-CONFIRMED】 管理平台配置（PDF 4.1.5）
- 【AI-DECIDED】 异常情况下停用存在重大风险的账号（必须记录原因和操作记录）

#### 默认不能

- 【AI-DECIDED】 不可直接修改学校内部成绩
- 【AI-DECIDED】 不可审核普通校内成绩
- 【AI-DECIDED】 不可代替学校管理员配置校内活动
- 【AI-DECIDED】 不可直接处理普通校内申诉（仅处理升级事项）
- 【AI-DECIDED】 不可修改学校上传的原始素材
- 【AI-DECIDED】 不得日常创建、编辑或管理学生和普通老师业务账号。
- 【AI-DECIDED】 出现重大安全风险时，可以紧急锁定或停用学生和普通老师账号。
- 【AI-DECIDED】 紧急操作必须填写原因、通知对应学校管理员并写入审计记录。
- 【AI-DECIDED】 风险解除后，账号解锁或重新启用由对应学校管理员执行；超级管理员确需直接恢复时必须记录原因并审计。

## 3. 权限边界（已冻结）

| 边界问题 | 学生 | 普通老师 | 学校管理员 | 超级管理员 |
|----------|:----:|:------:|:--------:|:--------:|
| 查看其他学生个人成绩明细 | 禁止 | 禁止 | 允许（本校授权范围） | 禁止；仅可查看汇总与必要审计信息 |
| 修改成绩 | 禁止 | 审核前/驳回后 | 审核前/驳回后+申诉更正 | 禁止 |
| 审核成绩 | 禁止 | 禁止 | 允许(本校，不可自审) | 禁止 |
| 日常创建和编辑师生账号 | 禁止 | 禁止 | 允许(本校) | 禁止 |
| 紧急锁定或停用高风险师生账号 | 禁止 | 禁止 | 允许(本校) | 允许(必须审计) |
| 解锁和重新启用师生账号 | 禁止 | 禁止 | 允许(本校) | 日常禁止；特殊情况允许，必须审计并通知学校管理员 |
| 物理删除有数据的对象 | 禁止 | 禁止 | 禁止 | 禁止 |
