## 3. 成绩尝试与有效成绩（已冻结）

### 3.1 成绩尝试

- 【AI-DECIDED】 同一学生在同一活动项目中可以有多次成绩尝试
- 【AI-DECIDED】 每次尝试单独记录，分别审核
- 【AI-DECIDED】 历史尝试作为历史记录保留

### 3.2 有效成绩选择规则

| 规则 | 说明 | 标签 |
|------|------|------|
| 最好成绩 | 依项目比较方向取最优 | AI-DECIDED（默认） |
| 最后一次成绩 | 取最近一次审核通过的 | AI-DECIDED |
| 管理员指定 | 校管手动选择 | AI-DECIDED |

- 【AI-DECIDED】 每个活动项目必须指定有效成绩选择规则，默认使用最好成绩
- 【AI-DECIDED】 只有审核通过的成绩才能成为有效成绩
- 【AI-DECIDED】 只有当前有效成绩参与排行榜
- 【AI-DECIDED】 无效或被替代成绩继续作为历史记录保留

### 3.3 成绩业务发生时间

- 【AI-DECIDED】 成绩记录必须包含"成绩业务发生时间"，即学生实际完成该次挑战的时间。
- 【AI-DECIDED】 成绩业务发生时间不得使用录入时间、提交时间或审核时间代替。
- 【AI-DECIDED】 成绩记录必须包含时间来源（学生自述/老师确认/现场记录/其他证据）。
- 【AI-DECIDED】 异常补录的成绩必须标记"是否人工补录"并关联原始记录或证据。
- 【AI-DECIDED】 无可靠业务发生时间的成绩，在需要打破并列时视为无完成时间。

## 9. 异常补录（已冻结）

### 适用场景

- 活动已结束后发现成绩漏录；
- 因设备或网络故障未能及时录入；
- 申诉成立后需要补录原不存在的成绩记录；
- 其他经学校管理员确认的特殊情况。

### 发起主体

| 角色 | 权限 | 标签 |
|------|------|------|
| 普通老师 | 可对本人负责的活动项目发起异常补录申请 | AI-DECIDED |
| 学校管理员 | 可对本校活动项目发起异常补录申请 | AI-DECIDED |
| 学生 | 不得直接发起异常补录，只能通过申诉提出问题 | AI-DECIDED |

### 异常补录状态

| 状态 | 含义 | 前置状态 | 后续状态 | 操作主体 | 是否终态 |
|------|------|---------|---------|---------|:--:|
| 草稿 | 发起人正在填写 | — | 待审批、已终止 | 发起人 | 否 |
| 待审批 | 已提交另一名学校管理员审批 | 草稿 | 已驳回、已批准待录入 | 审批人 | 否 |
| 已驳回 | 审批不通过 | 待审批 | 草稿（修改后重提） | 审批人 | 否 |
| 已批准待录入 | 审批通过，等待创建成绩草稿 | 待审批 | 成绩审核中 | 录入者 | 否 |
| 成绩审核中 | 已创建成绩记录并进入正常审核 | 已批准待录入 | 已完成 | 学校管理员 | 否 |
| 已完成 | 补录成绩审核通过 | 成绩审核中 | — | — | 是 |
| 已终止 | 补录申请被撤销或无法继续 | 草稿、待审批 | — | 发起人 | 是 |

### 异常补录流程

```
发起异常补录申请 → 填写原因和证据 → 另一名学校管理员审批 →
审批通过 → 创建成绩草稿 → 提交正常成绩审核 →
审核通过 → 重新计算相关排行榜
```

### 职责分离

- 【AI-DECIDED】 异常补录发起人与审批人必须不同。
- 【AI-DECIDED】 异常补录审批人与成绩录入人必须不同。
- 【AI-DECIDED】 成绩录入人与最终成绩审核人必须不同。
- 【AI-DECIDED】 异常补录审批人与最终成绩审核人允许相同，但必须在记录中保留两个独立操作节点。
- 【AI-DECIDED】 若希望更严格职责分离，可配置为三人，但V1不强制。

### 驳回重提

- 【AI-DECIDED】 已驳回申请可以修改后重新提交。
- 【AI-DECIDED】 重新提交应增加申请版本，不覆盖原审批记录。

### 异常补录记录字段

| 字段 |
|------|
| 学校 |
| 活动 |
| 活动项目 |
| 学生 |
| 补录原因 |
| 证据附件 |
| 发起人 |
| 审批人 |
| 审批结果 |
| 审批意见 |
| 驳回原因 |
| 申请版本 |
| 关联成绩记录 |
| 创建时间 |
| 完成时间 |

- 【AI-DECIDED】 异常补录审批通过不等于成绩审核通过。
- 【AI-DECIDED】 异常补录成绩仍需进入正常审核流程。
- 【AI-DECIDED】 异常补录导致排行榜变化时必须生成新排行榜版本。
