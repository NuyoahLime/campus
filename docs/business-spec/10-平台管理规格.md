## 1. 超级管理员定位

- 【SOURCE-CONFIRMED】 平台运营管理人员（PDF 4.1.5）
- 【AI-DECIDED】 超管是平台治理角色，不等于学校内部业务管理员
- 【AI-DECIDED】 "全平台数据"不等于"默认拥有所有学校内部操作权限"

---

## 2. 可执行操作（已冻结）

### 2.1 学校管理

- 【SOURCE-CONFIRMED】 审核学校入驻
- 【AI-DECIDED】 管理学校基础信息（关键信息修改）
- 【AI-DECIDED】 暂停学校
- 【AI-DECIDED】 恢复学校
- 【AI-DECIDED】 停用学校
- 【AI-DECIDED】 重新启用学校

> 【AI-DECIDED】 所有学校状态操作（暂停、恢复、停用、重新启用）必须填写原因并保存操作记录。

### 2.2 用户管理

- 【SOURCE-CONFIRMED】 管理学校管理员账号的待激活、正常、锁定和停用状态；对学校管理员账号执行解锁和重新启用
- 【AI-DECIDED】 超管不日常管理老师和学生业务资料（由校管管理）
- 【AI-DECIDED】 紧急情况下锁定或停用高风险师生账号
- 【AI-DECIDED】 所有跨学校紧急账号操作必须写入审计记录
- 【AI-DECIDED】 异常情况下可停用存在重大风险的账号，必须记录原因和操作记录

### 2.3 项目与内容

- 【SOURCE-CONFIRMED】 管理挑战项目及分类
- 【AI-DECIDED】 审核拟进入平台公共区域的活动基本信息、活动成果、素材和排行榜数据授权
- 【AI-DECIDED】 审核L3排行榜数据授权；暂停异常授权；恢复已暂停授权
- 【AI-DECIDED】 因学校停用或严重风险撤回授权
- 【AI-DECIDED】 超级管理员不得代替学校管理员新建校内数据授权
- 【SOURCE-CONFIRMED】 管理平台公开排行榜

### 2.4 反馈与系统

- 【SOURCE-CONFIRMED】 处理平台级反馈和升级事项
- 【SOURCE-CONFIRMED】 查看平台运行统计和审计信息
- 【SOURCE-CONFIRMED】 管理平台配置

## 3. 默认禁止（已冻结）

| 操作 | 原因 | 标签 |
|------|------|------|
| 日常创建、编辑师生账号 | 校管职责 | AI-DECIDED |
| 日常调整师生角色和学校归属 | 校管职责 | AI-DECIDED |
| 直接修改学校内部成绩 | 超管不越级 | AI-DECIDED |
| 审核普通校内成绩 | 职责分离 | AI-DECIDED |
| 代替校管配置校内活动 | 学校自治 | AI-DECIDED |
| 修改学校上传的原始素材 | 超管不修改学校数据 | AI-DECIDED |
| 处理普通校内申诉（仅处理升级事项） | 优先校管 | AI-DECIDED |
| 修改素材校内使用状态 | 校管职责 | AI-DECIDED |

## 4. 紧急治理例外（已冻结）

- 【AI-DECIDED】 重大安全风险下，超级管理员可以紧急锁定或停用师生账号。
- 【AI-DECIDED】 紧急操作必须记录风险类型、风险等级、操作原因和操作时间。
- 【AI-DECIDED】 必须通知学校管理员。
- 【AI-DECIDED】 解锁和恢复由学校管理员执行；特殊情况下超级管理员可以直接恢复，必须记录原因并审计。
- 【AI-DECIDED】 特殊情况下超级管理员可以直接恢复，但必须记录原因。
- 【AI-DECIDED】 紧急权限不得用于普通离职、毕业、转班等日常管理事项。

## 5. 超管权限边界总结

| 问题 | 决策 |
|------|------|
| 查看学校内部成绩 | 【AI-DECIDED】 可查看汇总和审计信息，不可查看学生个人成绩明细 |
| 修改学校内部成绩 | 【AI-DECIDED】 禁止 |
| 处理学校内部申诉 | 【AI-DECIDED】 禁止（仅处理升级事项） |
| 审核学校内部素材 | 【AI-DECIDED】 不参与校内审核（仅平台公开审核） |
| 处理学校内部反馈 | 【AI-DECIDED】 查看允许，处理禁止（仅处理升级/平台级） |
| 管理师生账号 | 【AI-DECIDED】 禁止（仅管理校管账号） |
| 跨校数据访问 | 【AI-DECIDED】 需显式切换学校上下文 |
| 访问个人明细数据 | 【AI-DECIDED】 汇总数据不得包含可直接识别单个学生的成绩明细；因安全、投诉升级或审计需要访问个人数据时，必须经过显式授权并记录访问原因、访问人和访问时间 |
