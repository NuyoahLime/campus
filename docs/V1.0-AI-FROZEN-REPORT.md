## 四、关键决策亮点

### 4.1 冲突消解

| 冲突 | 解决方案 |
|------|---------|
| CNF-004 活动流程矛盾 | 两条路径并存：老师申请→校管审批 + 校管直接创建。MVP 无需超管审核 |
| CNF-005 成绩录入角色矛盾 | 校管**可以**录入成绩（采纳 PDF 1.2 节明确描述） |
| CNF-009 素材审核层级 | 单层审核（校管审核），超管保留抽查权 |
| CNF-010 排行榜类型 | 两种：本校排行榜（校内）+ 全平台排行榜（公开） |

### 4.2 超管权限边界

- 可查看学校内部数据（用于平台监控），但不可直接修改
- 不可处理学校内部申诉（优先校管）
- 不可越级管理学校内部师生账号
- 不可参与日常素材审核（保留抽查/举报处理权限）

### 4.3 关键业务规则

- 活动状态机：草稿→已发布→进行中→已结束→成果已发布
- 成绩闭环：录入→审核→生效→排行→申诉→修正
- 同一学生同一项目多次录入，取最优成绩
- 审核通过后成绩仅可通过申诉流程修改
- 申诉窗口期：成绩公布后 7 天
