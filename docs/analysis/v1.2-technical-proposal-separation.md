## 降级处理

以下结论从"冻结"降级为PROPOSAL：

1. **204个端点**: 是API代理的技术建议。规格中无端点定义。API设计阶段重新确定。
2. **22张主表+6张版本表+15张审计表**: 是数据库代理的技术建议。规格中无表结构定义。数据库逻辑设计阶段重新确定。
3. **46个异步事件**: 是API代理的技术建议。规格中有通知事件清单（FACT），但"46个"是代理计数。事件实现方案在技术设计阶段确定。
4. **JWT/URL schoolId**: 是API代理的技术建议。学校隔离是FACT，具体实现方案是PROPOSAL。

## 结论

- **业务事实**（已冻结）: 约12条核心规则，全部有明确证据
- **DERIVED**（可从事实推导）: 逻辑删除、超管上下文切换等
- **PROPOSAL**（技术建议）: 所有数据库表数量、API端点数量、架构方案、认证方案
