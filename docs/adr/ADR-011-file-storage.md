# ADR-011: 文件存储

> **状态**: Accepted
> **日期**: 2026-07-14

---

## 背景

系统需要上传图片(≤10MB JPG/PNG)和视频(≤500MB MP4)。文件元数据属于Media聚合，文件二进制必须与领域聚合分离。

## FACT

- R5: 文件元数据与二进制分离(ADR-003)
- F10: 图片≤10MB, 视频≤500MB (08 §3)
- R8: 已被历史业务引用的文件不得自动物理删除

## 候选方案

### 方案A: S3兼容接口(所有环境, 本地MinIO) (推荐)
### 方案B: 本地文件系统(dev) + S3(prod)
### 方案C: 数据库BLOB

---

## TECH_DECISION

**选择方案A: 所有环境统一S3兼容接口。**

| 项目 | 决定 |
|------|------|
| 接口 | S3兼容 |
| 本地开发 | Docker Compose MinIO |
| 测试 | Testcontainers MinIO |
| 生产 | S3兼容对象存储(厂商不锁定) |
| 元数据 | PostgreSQL |
| 二进制 | 对象存储 (不入PostgreSQL) |

## 上传策略

1. 小图片: 后端代理上传
2. 大视频: 预签名分片或直传(优先)
3. 上传完成后: 后端确认对象存在、大小、类型和校验值
4. 未完成/孤立上传: 需要清理机制
5. 业务下架 ≠ 物理删除: 已被历史引用的文件不得自动物理删除
6. V1不实现视频转码
7. 病毒扫描、内容审核和转码保留扩展点

## 拒绝方案

- **方案B(混合)**: 环境不一致导致dev/prod差异bug
- **方案C(BLOB)**: 500MB视频不适合数据库存储
